# FlyRank CRUD API — Task Management System

A lightweight RESTful CRUD API built with Python and FastAPI for managing a task list.

## 🚀 Tech Stack
- **Language:** Python 3
- **Framework:** FastAPI
- **Data Validation:** Pydantic
- **ASGI Server:** Uvicorn
